# БЫТОВКИн — главная страница

Одностраничный сайт на React, TypeScript, Vite и React Three Fiber. Первая версия работает локально; форма заявки демонстрационная.

## Запуск

На Windows откройте `start-site.cmd` двойным щелчком и оставьте открывшееся окно запущенным. Сайт откроется в браузере. Если браузер не открылся сам, перейдите по адресу, показанному в окне (обычно `http://127.0.0.1:5173/`).

Если файл сообщает об отсутствующих зависимостях, выполните в терминале из папки проекта:

```powershell
pnpm install --config.enable-global-virtual-store=false --store-dir .pnpm-store --virtual-store-dir node_modules/.pnpm
./start-site.cmd
```

Для проверки типов и сборки:

```powershell
.\node_modules\.bin\tsc.cmd --noEmit
.\node_modules\.bin\vite.cmd build
```

В обычной среде после установки также доступны скрипты `pnpm dev`, `pnpm typecheck` и `pnpm build`. Прямой запуск бинарников показан выше, поскольку изолированная среда Codex на Windows ограничивает служебную символическую ссылку pnpm.

## Что редактировать перед запуском

- Контакты, географию, статистику, карточки моделей и проекты — в `src/data/site.ts`.
- Логотип сейчас текстовый; замените компонент `Logo` в `src/App.tsx` после получения фирменного файла.
- Добавьте разрешённое видео в `public/video/production.mp4`, затем задайте `heroVideoSrc = '/video/production.mp4'` в `src/data/site.ts`. Пока используется локальный постер `public/images/workshop-hero.jpg`.
- Замените иллюстрации в `public/images/` на согласованные фотографии компании и проектов. Каждое текущее изображение помечено на странице как иллюстрация.
- Подтвердите телефон, мессенджеры, точный адрес, режим работы и показатели. Карта показывает обзор Чебоксар без метки производства.
- Подключите backend приёма заявок и разместите политику обработки персональных данных. Сейчас форма лишь проверяет поля в браузере и честно сообщает, что ничего не отправлено.

## Vercel

Проект настроен для статической сборки Vite: `pnpm run build` создаёт папку `dist`, которую публикует Vercel. Конфигурация находится в `vercel.json`. После подключения GitHub-репозитория новые коммиты в основную ветку вызывают сборку на Vercel. Перед публичным запуском замените временные материалы и подтвердите указанные на странице сведения.

## Конструктор

Можно выбрать три базовые модели, изменить размеры, добавить и перетащить окна, двери и перегородки, переключать стены и положение с помощью полей, добавить боковой модуль, а для блок-контейнера — верхний. Доступны внешний вид, вид сверху и интерьер. Конфигурация сохраняется в `localStorage` с версией формата и проверкой повреждённых данных. Ограничения размещения являются визуальными; инженерный расчёт конструкции не выполняется.

## Временные изображения

Семь изображений в `public/images/` созданы встроенным imagegen и затем оптимизированы в JPEG. Использованы запросы на: широкий постер сборки стального каркаса в цеху; интерьер производственного цеха; архитектурную визуализацию блок-контейнера; дачную бытовку на участке; строительную бытовку на производственной площадке; парковый павильон; составное модульное здание в северном пейзаже. Во всех запросах указаны отсутствие логотипов, текста и водяных знаков. Эти изображения не являются фотографиями реализованных объектов компании.
